2. Pipeline completion time

Pipeline cards showed run_date and duration but not what time of day the Lambda actually finished — the API already returns completed_at, just wasn't rendered. Added formatCompletedAt() in PipelineStatus.jsx: appends "Z" to the backend's naive-UTC timestamp so the browser parses it as UTC, then renders in the viewer's local time zone. The click-to-link design (this turn's main build)

User asked how to visually connect a Slate row to its pitchers. Recommended a hybrid over two other options (accordion-in-place, or nothing) to keep both the "scan all of today's starters" view and a concrete link:

  • Shared color dot (lib/gameColor.js) — deterministic by game_pk % 6, using the user's own portfolio accent palette (petrol-teal, vangogh-navy, wheat-gold, olive, terracotta, cloud-grey) — not invented from scratch.
  • Click a Slate row — scrolls to and pulses (green flash, 1.4s) that game's <tbody id="predictions-game-{game_pk}"> in Section 4. Plain DOM manipulation between sibling components, no global store introduced for a one-off visual nudge.
  • Section 4 rows grouped per game (one <tbody> per game_pk) rather than a flat list — this is also what makes the scroll target addressable.
  • Added an italic "predicted, not realized" caption per the user's point that the numbers weren't clearly marked as predictions.
